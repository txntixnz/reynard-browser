# Pinned 0.19.0 bridge headers

Derived from Firefox commit 9378fbc58660847fbc02c3486a0ecd6049978e25 by applying
Reynard 0.19.0 commit 24a99b717ca82aa8ac9777123692a653cc8bf4ee's unmodified
IOSBootstrap, GeckoViewSwiftSupport and GeckoViewRuntimeSupport header patches. Original MPL notices are retained.

The browser-only build verifies exact engine/patch sources and the official
0.19.0 TrollStore package's SHA-256, version and build before using Gecko158.0.1.
The Swift bridge includes the new error-page and certificate/HTTPS-only APIs.
Older release headers and preparation modes remain available on their branches.

The unmodified `nsError.h` (xpcom/base) and `mozilla/Likely.h` (mfbt) are also
from that Firefox commit. `ErrorList.h` is generated by the included unmodified
`source/ErrorList.py` using its `error_list_h(output)` entry point, without extra
error modules. These are required by 0.19's WebRequestErrorBridge.mm; no engine
binary or bridge implementation is replaced. Package tests reproduce the header
and check every mapped symbol. The native regression suite compiles and runs the
actual bridge with these headers before building the full app.
